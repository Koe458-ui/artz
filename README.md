# Ored

An AI built from scratch — no pretrained weights, no downloaded corpus. The
model, the tokenizer, the training loop and the evaluation are all in this
repository, and the data they learn from is generated by code that is here too.

It is in its training phase.

- `ored/README.md` — how to run it, what the environment variables are, where
  the database and the checkpoints live
- `ored/model/README.md` — how the model works, what it learned, and why each
  piece is built the way it is

## Layout

| Path | What |
|---|---|
| `ored/` | the chat page and the model |
| `functions/api/ored.js` | the backend endpoint |
| `functions/lib/ored-*.js` | its helpers |
